# assets

Place your static files here. They are served at `/assets/` in the running app.

## Resume / CV

Current resume used by the homepage download section:

```
public/assets/resume-english.pdf
```

Public URL:

```
/assets/resume-english.pdf
```

```
public/assets/profile-placeholder.svg
```
